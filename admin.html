Sign in with your GitHub access token to change dishes and prices. You only need to do this once on each phone or computer.

Don't have a token yet? (2 minutes)
  1. Open this GitHub page and sign in to GitHub if asked.
  2. Under Expiration, choose No expiration (or a date you prefer).
  3. Leave the ticked box (public_repo) as it is, scroll down and click Generate token.
  4. Copy the token (it starts with ghp_) and paste it above.

Keep it private, like a password. Anyone with it can change your website.
